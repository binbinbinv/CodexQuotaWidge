# Codex 余量任务栏组件 1.0.5

在 Windows 任务栏右侧查看 Codex 的 5 小时和本周剩余额度，以及本周额度的重置时间。启动后会立即读取余量，正常情况下每 30 分钟刷新一次。

## 安装

1. 确认电脑使用 **Windows 11 x64**，并已安装、打开和登录 **Codex 桌面版**。
2. 双击 `CodexQuotaWidget-Setup-1.0.5.exe`，按向导点击「安装」。安装完成时保留「启动 Codex Quota Widget」勾选，点击「完成」。
3. 在底部任务栏的通知区域左侧查看组件。

安装包只有一个 `.exe` 文件，无需解压或运行脚本。它只为当前 Windows 用户安装，不需要管理员权限。已有旧版可直接覆盖安装。此安装包未签名；如果 Windows 提示未知发布者，请先核对文件来源。

## 日常使用

- 单击组件：立即刷新余量。
- 右键组件：刷新、设置开机启动、查看日志或退出。
- 退出后重新打开：在开始菜单搜索 **Codex Quota Widget**。默认在登录 Windows 后自动启动。
- 全屏或任务栏收起时，组件会暂时隐藏。退出全屏或展开任务栏即可看到。

如果显示同步失败，先打开 Codex 桌面版，确认已登录，再单击组件刷新。仍有问题时，可以右键打开日志目录查看原因。此组件是独立工具，使用目标电脑本地登录的 Codex 账户，安装包不包含账号或凭据。

## 卸载

打开「设置 → 应用 → 已安装的应用」，找到 **Codex Quota Widget**，选择「卸载」。卸载组件不会卸载 Codex 桌面版，也不会清除其登录信息。
